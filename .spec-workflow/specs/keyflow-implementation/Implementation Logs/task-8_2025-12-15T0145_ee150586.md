### Integrations

#### Integration
- **Description:** DraggableNode integrates with DragController provider to manage drag state and with nodePositionsProvider to persist node positions after dragging completes
- **Frontend Component:** DraggableNode
- **Backend Endpoint:** nodePositionsProvider.setPosition()
- **Data Flow:** User starts pan gesture → DragController.startDrag() → User drags → DragController.updateDrag() → Visual feedback updates (elevation, shadow) → User releases → DragController.endDrag() → _constrainPosition() applies bounds → nodePositionsProvider.setPosition() persists to SharedPreferences → State update triggers rebuild with new position

#### Integration
- **Description:** FlowEditorPage wraps all flow nodes with DraggableNode to enable drag-and-drop repositioning within the InteractiveViewer canvas
- **Frontend Component:** FlowEditorPage
- **Backend Endpoint:** DraggableNode wrapper
- **Data Flow:** FlowEditorPage renders nodes → Each node wrapped in DraggableNode → DraggableNode uses Positioned widget with current position from dragController or initialPosition → User interaction triggers drag → Position updates flow through DragController → Final position persists via nodePositionsProvider
