# Dart FFI Codegen Migration Guide

## Overview

The KeyRX project has migrated from Python-based Dart FFI binding generation to a Rust-based code generator. This document explains the differences and migration process.

## Background

Previously, the project used two code generators:
- **Python script** (`scripts/generate_dart_bindings.py`): Generated `ui/lib/ffi/generated/bindings_generated.dart`
- **Rust tool** (`core/tools/generate_dart_bindings`): Generated `ui/lib/ffi/generated_bindings.dart` and `ui/lib/models/generated_models.dart`

As of task 12 (Codegen Tool Consolidation), the Python script has been removed in favor of the Rust tool.

## Key Differences

### Python Script (Deprecated)
- Single output file: `bindings_generated.dart`
- Generated a monolithic `KeyrxBindingsGenerated` class
- Simple typedef generation
- No incremental generation
- Manual execution required

### Rust Tool (Current)
- Two output files:
  - `ui/lib/ffi/generated_bindings.dart` - FFI bindings
  - `ui/lib/models/generated_models.dart` - Dart model classes
- Domain-specific binding classes (e.g., `DiscoveryBindings`, `EngineBindings`)
- High-level wrapper functions with automatic error handling
- **Incremental generation** with SHA256 caching
- **Watch mode** support
- Multiple CLI flags (`--check`, `--force`, `--domain`, `--verbose`)
- Integrated with `just` commands

## Feature Parity

The Rust tool has complete feature parity with the Python script, plus additional capabilities:

| Feature | Python | Rust |
|---------|--------|------|
| Contract parsing | ✅ | ✅ |
| Type mapping | ✅ | ✅ |
| Bindings generation | ✅ | ✅ |
| Model generation | ❌ | ✅ |
| Incremental generation | ❌ | ✅ |
| Check mode (CI) | ❌ | ✅ |
| Domain filtering | ❌ | ✅ |
| Verbose output | ✅ | ✅ |
| Dart formatting | ✅ | ✅ |
| Watch mode | ❌ | ✅ (via `ffi_watch.sh`) |

## Migration Steps

### For Developers

1. **Remove Python dependency**: The Python script is no longer needed
2. **Use Rust tool**: All binding generation now uses `just gen-dart-bindings`
3. **Watch mode**: Use `just ffi-watch` for automatic regeneration during development

### Commands

#### Before (Python)
```bash
python3 scripts/generate_dart_bindings.py
```

#### After (Rust)
```bash
# Generate all bindings
just gen-dart-bindings

# Check if bindings are up-to-date (CI)
just check-dart-bindings

# Watch mode (auto-regenerate on changes)
just ffi-watch

# Generate for specific domain only
cargo run --manifest-path core/tools/generate_dart_bindings/Cargo.toml -- --domain config

# Force regeneration (bypass cache)
cargo run --manifest-path core/tools/generate_dart_bindings/Cargo.toml -- --force
```

## CI/CD Integration

The CI pipeline uses the Rust tool via `just check-dart-bindings` to verify bindings are up-to-date.

See `.github/workflows/ci.yml` for the current integration.

## Output Structure

### Generated Files

```
ui/lib/
├── ffi/
│   ├── generated_bindings.dart   # FFI function bindings
│   └── generated/
│       └── bindings_generated.dart  # Legacy (no longer generated)
└── models/
    └── generated_models.dart      # Dart model classes
```

Note: The legacy `ui/lib/ffi/generated/bindings_generated.dart` file is no longer generated by the build system. The new file is at `ui/lib/ffi/generated_bindings.dart`.

## Troubleshooting

### "Bindings are out of date" in CI

Contracts were modified without regenerating bindings:

```bash
just gen-dart-bindings
git add ui/lib/ffi/generated_bindings.dart ui/lib/models/generated_models.dart
git commit --amend --no-edit
```

### "dart format not found"

Install the Dart SDK or allow the tool to continue with a warning (formatting is optional).

### Type mapping errors

Check that all parameter types in your contract are supported. See `core/tools/generate_dart_bindings/README.md` for the type mapping table.

## Rollback Plan

If issues arise, the Python script has been archived in git history:

```bash
# Retrieve the Python script (emergency only)
git show HEAD~1:scripts/generate_dart_bindings.py > scripts/generate_dart_bindings.py

# Generate using Python (emergency fallback)
python3 scripts/generate_dart_bindings.py
```

Note: This is for emergency use only. The Python script is no longer maintained.
