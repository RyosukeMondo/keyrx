# Utility Scripts

Manual helper scripts not invoked by automation.

## Scripts

| Script | Purpose | Usage |
|--------|---------|-------|
| `add_instrumentation.sh` | Add tracing to Rust code | Manual |
| `split_module.sh` | Split large modules | Manual |
| `check_regression.py` | Performance regression check | Manual |

## Note

These scripts are not referenced in the justfile or CI workflows. They are kept as manual development utilities.
